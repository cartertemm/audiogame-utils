Audiogame Utils playground

This page renders all of the interactive examples that you can run to get a feel for how things work. We aim to support all of the features supported by the library.

  • Input test - shows how to react to keyboard input by speaking events with text to speech on iOS, or a screen reader on any other operating system.

Something broken? Wish a feature existed that doesn't yet? Submit an issue in our issue tracker.
